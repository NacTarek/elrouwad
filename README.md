# استوديو منشورات الرواد

صفحة واحدة (`index.html`) لصنع منشورات مؤسسة الرواد للتربية والتعليم:
منشورات الصور حسب الفرع، المناسبات، أغلفة الريلز، والتعازي.

كل شيء داخل الملف نفسه: الخطوط، الشعار، الأنماط، الصور التجريبية وأداة الضغط (ZIP).
لا يحتاج إلى إنترنت ولا إلى خادم، ويعمل حتى بفتحه مباشرة من الحاسوب.

---

## الاستعمال المباشر (بدون إنترنت)

انقر مرتين على `index.html` فيفتح في المتصفح (Chrome أو Edge أو Firefox أو Safari).

## النشر على GitHub Pages (رابط ثابت للفريق)

1. ادخل إلى <https://github.com> وأنشئ حسابًا إن لم يكن لديك.
2. اضغط **New repository**، وسمّه مثلًا `rouwad-studio`، ثم **Create repository**.
3. اضغط **uploading an existing file** (أو **Add file ← Upload files**)، واسحب `index.html` و`README.md`، ثم **Commit changes**.
4. ادخل إلى **Settings ← Pages**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` و `/ (root)` ثم **Save**
5. بعد دقيقة أو دقيقتين يظهر الرابط:
   `https://اسم-حسابك.github.io/rouwad-studio/`

**لتحديث الصفحة لاحقًا:** ارفع ملف `index.html` الجديد في نفس المستودع فيحلّ محلّ القديم.

## بدائل أسهل من GitHub

- **Netlify Drop**: افتح <https://app.netlify.com/drop> واسحب المجلد كاملًا، فتحصل على رابط فورًا.
- **Cloudflare Pages**: يقبل رفع المجلد مباشرة، ويمكن حمايته بكلمة سر أو بقائمة بريد إلكتروني (Cloudflare Access).

## ملاحظات مهمة

- **الحفظ في المتصفح:** الملصقات المرفوعة وآخر نص وإعدادات كل قالب تُحفظ في المتصفح الذي تستعمله فقط، ولا تنتقل بين الأجهزة. الصور لا تُرفع إلى أي مكان.
- **على الهاتف:** زر التنزيل يفتح قائمة المشاركة، فاختر «حفظ الصورة» لتذهب إلى المعرض.
- **المقاسات:**

  | القالب | المقاس عند التنزيل |
  |---|---|
  | منشورات الصور والمناسبات | 2160×2160 |
  | أغلفة الريلز | 1080×1920 |
  | التعازي | 2160×2700 |

- **الخطوط (مهم):** الصفحة تحتوي على خطَّي **Graphik Arabic** و**Granadia** مدمجين، وهما خطان تجاريان.
  إذا كان المستودع **عامًا (Public)** فبإمكان أي شخص استخراج ملفات الخطوط من الصفحة.
  - تأكّدوا من أن رخصة الخط تسمح بالاستعمال على الويب.
  - أو اجعلوا المستودع **خاصًا (Private)**. نشر Pages من مستودع خاص يحتاج اشتراك GitHub Pro.
  - أو استعملوا Cloudflare Pages مع حماية بكلمة سر.
- أُضيفت للصفحة علامة `noindex` حتى لا تظهر في نتائج محركات البحث.
- **خطّا Abril Fatface و Noto Sans Tifinagh** المستعملان في قالب يناير مجانيان (رخصة OFL).
